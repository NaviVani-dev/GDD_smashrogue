# Glosario

## Descripción de la sección

Centraliza términos técnicos, de diseño y propios del universo del videojuego.

| Término       | Definición                                                                                   |
| -------------- | --------------------------------------------------------------------------------------------- |
| GDD            | Documento de Diseño de Videojuego.                                                           |
| Mecánica      | Regla o interacción mediante la cual el jugador puede actuar.                                |
| Sistema        | Conjunto de componentes y reglas que trabajan juntos.                                         |
| MVP            | Producto Mínimo Viable.                                                                      |
| Vertical Slice | Muestra pequeña pero representativa del producto final.                                      |
| Prototipo      | Versión jugable inicial del proyecto en Unity. Los valores pueden cambiar con el balance      |
| Roguelike      | Género donde cada partida es distinta y, al perder, se empieza de nuevo.                     |
| Moveset        | Conjunto de ataques y habilidades de un personaje.                                            |
| HUD            | Información que se muestra en pantalla durante la partida (porcentajes, vidas, piso, etc.)   |
| UI             | Interfaz de usuario, en la que se encuentran los menús y las pantallas donde el jugador interactúa |
| NPC            | Personajes no jugables                                                                        |
| 2.5D           | Perspectiva con desplazamiento lateral y escenarios que muestran profundidad                  |
| Cel-shading    | Sombreado plano con bloques de luz y sombra de bordes nítidos, sin degradados                |

## Términos de combate

| Término              | Definición                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| Porcentaje de daño   | Valor de 0% a 999% que sube al recibir golpes. Entre más alto, más lejos sale volando el personaje. |
| Knockback (retroceso) | Fuerza con la que un golpe lanza al personaje; depende de su porcentaje y su peso.                    |
| KO                    | Eliminación de un personaje al salir de los límites del escenario: por una ventana o pared rota, o al caer por el borde de la plataforma.                               |
| Hitlag                | Congelación breve del golpe al conectar, para que el impacto se sienta.                              |
| Ataque básico        | Ataque en todas direcciones con el botón de ataque (neutral, lado, arriba, abajo y en carrera).      |
| Habilidad (especial)  | Ataque en todas direcciones con el botón de habilidad. La de arriba sirve de recuperación.          |
| Ataque fuerte (smash) | Ataque hacia el lado, arriba o abajo que se puede cargar.                                             |
| Escudo                | Bloquea golpes, pero se desgasta. Si se rompe, el personaje queda aturdido.                           |
| Parry                 | Soltar el escudo justo cuando llega un golpe; deja expuesto al atacante.                                               |
| Esquive               | Movimiento con un momento de invulnerabilidad, en el suelo o en el aire.                              |
| Susceptibilidad       | Multiplicador del porcentaje que recibe un personaje por golpe. Los enemigos normales empiezan en ×2.0 y los élites en ×1.2; los personajes jugables reciben ×1.0.         |
| Estado alterado       | Efecto temporal, como quemadura o lentitud.                                                           |
| Ventana rompible      | Pared lateral del escenario que se rompe con un golpe muy fuerte y se regenera después. En las salas cerradas, las paredes funcionan igual. |

## Términos de progresión y contenido

| Término       | Definición                                                                                |
| -------------- | ------------------------------------------------------------------------------------------ |
| Piso / Nivel   | Cada arena de combate del rascacielos. La subida no tiene límite de pisos.                 |
| Ronda          | Grupo de hasta 4 enemigos dentro de un piso. Al subir, hay más enemigos y más rondas.      |
| Boon           | Mejora que se elige al terminar un piso. No hay límite fijo de boons; cada uno llega hasta el nivel 5. |
| Mejora         | Aumento de nivel de un boon que el jugador ya tiene.                                       |
| Enemigo élite | Guardia pesado más fuerte e inteligente, con borde dorado y el porcentaje en color cian. Lleva un boon que suelta al ser derrotado. |
| Jefe           | Mr. Big Data, CEO de Nuddle. Aparece cada 50 pisos y tiene barra de vida.                  |
| Tienda         | Cafetería Café Corp en los pisos 10, 20, 30, 40, 49, 60, 70, 80, 90, 99… para comprar con monedas. |
| Monedas        | Recurso que sueltan los enemigos (de 0 a 10). Solo sirven dentro de la partida actual.     |
| Vidas          | El jugador tiene 3. Se pierde una al salir del escenario.                                  |

## Términos del universo del juego

| Término                 | Definición                                                                                                |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Nuddle                   | Compañía parodia de Google. Es la compañía de la entrega.                                              |
| Bookworm                 | Compañía parodia de Facebook.                                                                            |
| Nile                     | Compañía parodia de Amazon.                                                                              |
| Y (se pronuncia "Why")   | Compañía parodia de X (Twitter).                                                                         |
| La Coladera              | Base secreta de la resistencia en el viejo alcantarillado. Solo existe en el lore; no es un lugar jugable. |
| Resistencia              | Grupo de Niko, Mateo Cruz, Mr. Wobbles, Atsuko y Craub contra las corporaciones.                           |
| CEO                      | Jefe de cada compañía. En Nuddle, Mr. Big Data aparece cada 50 pisos.                                    |
