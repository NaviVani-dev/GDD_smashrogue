# Glosario

## Descripción de la sección

Centraliza términos técnicos, de diseño y propios del universo del videojuego.

| Término       | Definición                                                                                   |
| -------------- | --------------------------------------------------------------------------------------------- |
| GDD            | Documento de Diseño de Videojuego.                                                           |
| Mecánica      | Regla o interacción mediante la cual el jugador puede actuar.                                |
| Sistema        | Conjunto de componentes y reglas que trabajan juntos.                                         |
| MVP            | Producto Mínimo Viable.                                                                      |
| Vertical Slice | Muestra pequeña pero representativa del producto final.                                      |
| Prototipo      | Version jugable inicial del proyecto en Unity. Los valores pueden cambiar con el balance      |
| Roguelike      | Género donde cada partida es distinta y, al perder, se empieza de nuevo.                     |
| Moveset        | Conjunto de ataques y habilidades de un personaje.                                            |
| HUD            | Información que se muestra en pantalla durante la partida (porcentajes, vidad, nivel, etc)   |
| UI             | Interfaz de usuario, en la cuál se encuentra menús y pantallas donde el jugador interactúa |
| NPC            | Personajes no jugables                                                                        |
| 2.5D           | Perspectiva con desplazamiento lateral y escenarios que muestran profundidad                  |
| Cel-shading    | Sombreado plano con bloques de luz y sombra de bordes nítidos, sin degradados                |

## Términos de combate

| Término              | Definición                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| Porcentaje de daño   | Valor de 0% a 999% que sube al recibir golpes. Entre más alto, más lejos sale volando el personaje. |
| Knockback (retroceso) | Fuerza con la que un golpe lanza al personaje; depende de su porcentaje y su peso.                    |
| KO                    | Eliminación de un personaje al salir de los límites del escenario.                                  |
| Hitlag                | Congelación breve del golpe al conectar, para que el impacto se sienta.                              |
| Ataque básico        | Ataque en todas direcciones con el botón de ataque (neutral, lado, arriba, abajo y en carrera).      |
| Habilidad (especial)  | Ataque en todas direcciones con el botón de habilidad. La de arriba sirve de recuperación.          |
| Ataque fuerte (smash) | Ataque hacia el lado, arriba o abajo que se puede cargar.                                             |
| Escudo                | Bloquea golpes, pero se desgasta. Si se rompe, el personaje queda aturdido.                           |
| Parry                 | Bloqueo justo a tiempo que deja expuesto al atacante.                                                 |
| Esquive               | Movimiento con un momento de invulnerabilidad, en el suelo o en el aire.                              |
| Susceptibilidad       | Cuánto porcentaje recibe un personaje por golpe. Los enemigos reciben más que el jugador.           |
| Estado alterado       | Efecto temporal, como quemadura o lentitud.                                                           |
| Ventana rompible      | Pared lateral del escenario que se rompe con un golpe muy fuerte y se regenera después.              |

## Términos de progresión y contenido

| Término       | Definición                                                                                |
| -------------- | ------------------------------------------------------------------------------------------ |
| Piso / Nivel   | Cada arena de combate del rascacielos. Una partida tiene hasta 100.                        |
| Ronda          | Grupo de enemigos dentro de un nivel (de 1 a 3 por nivel).                                 |
| Boon           | Mejora que se elige al terminar un nivel. Se pueden tener hasta 3, con 5 niveles cada uno. |
| Mejora         | Aumento de nivel de un boon que el jugador ya tiene.                                       |
| Enemigo élite | Enemigo más fuerte e inteligente, con el porcentaje en color dorado.                      |
| Mini-jefe      | Enemigo élite que aparece cada 20 niveles.                                                |
| Jefe final     | Enemigo del nivel 100. En la entrega, Bernard "Big Data" Nuddleman.                        |
| Ascensor       | Elemento de cada arena que se activa al terminar el nivel para subir al siguiente piso.    |
| Tienda         | Pausa en los niveles 10, 19, 30, 39, 50, 59, 70, 79, 90 y 99 para comprar con monedas.     |
| Monedas        | Recurso que sueltan los enemigos (de 0 a 5). Solo sirven dentro de la partida actual.      |
| Vidas          | El jugador tiene 3. Se pierde una al salir del escenario.                                  |

| Término                 | Definición                                                                                                |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |

| Bookworm                 | Compañía parodia de Facebook.                                                                            |
| Nile                     | Compañía parodia de Amazon.                                                                              |
| Y (se pronuncia "Why")   | Compañía parodia de X (Twitter).                                                                         |
| La Coladera              | Base secreta de la resistencia en el viejo alcantarillado. Solo existe en el lore; no es un lugar jugable. |

| CEO                      | Jefe de cada compañía, esperando en el último piso de su rascacielos.                                   |
