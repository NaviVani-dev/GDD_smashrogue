# Público y Plataforma

## Descripción de la sección

Define para quién se diseña el videojuego y dónde se jugará. Las decisiones de diseño, interfaz, controles y rendimiento dependen de estas variables.

## Público objetivo

**Edad aproximada:** 10 años en adelante

**Experiencia esperada:**  Casual y avanzada

> Casual, intermedia, avanzada.

**Intereses relevantes:** Jugadores regulares de juegos de peleas de plataformas

**Conocimientos previos necesarios:** Ninguno

## Plataforma

| Elemento                | Decisión                                           |
| ----------------------- | --------------------------------------------------- |
| Plataforma principal    | PC con Windows o Linux (build publicada en itch.io) |
| Plataformas secundarias | Xbox, PlayStation, Nintendo Switch y Steam Deck (lanzamiento futuro) |
| Método de entrada      | Teclado / Control                                   |
| Resolución objetivo    | 1920x1080 (el juego se abre a la resolución nativa del monitor) |
| Relación de aspecto    | 16:9 (en monitores con otra relación aparecen barras negras) |
| Rendimiento objetivo    | 60 FPS                                              |
| Conexión requerida     | No                                                  |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

* **Hardware:** requisitos mínimos de Windows 10 de 64 bits o Linux de 64 bits (Ubuntu 22.04 o posterior), Intel Core i3 o equivalente, GPU compatible con DirectX 11 (Windows) o con Vulkan / OpenGL 3.2 (Linux) y resolución de 1280 × 720 (ver [[03 - Requisitos Técnicos]]).
* **Memoria:** 8 GB de RAM como mínimo y 16 GB recomendados. Objetivo de hasta 4 GB de RAM durante la ejecución.
* **Almacenamiento:** 5 GB disponibles como mínimo y 10 GB recomendados.
* **Controles:** teclado y mando. No se usan mouse ni controles táctiles durante el combate.
* **Rendimiento:** depende de la complejidad de los escenarios, los efectos visuales y la cantidad de enemigos simultáneos.

## Sesión de juego

**Duración esperada de una sesión:** 20 mins

**Duración total estimada del juego:** No aplica: Cada partida dura hasta perder las 3 vidas.

## Modelo de distribución

> Gratuito, pago único, educativo, prototipo académico, etc.

**Modelo:** Pago único (lanzamiento final) y prototipo académico (entrega del proyecto).
